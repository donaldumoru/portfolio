# donaldumoru.com

Source code for my personal website, [donaldumoru.com](https://donaldumoru.com).

## History

The first version of this site was built with JSL3. The current version is built with React and TypeScript.

The design has changed quite a bit over time too. The current version leans more towards a _less is more_ approach.

I make changes to the site every now and then as my taste in design changes, or as I find different ways I want to build things.
